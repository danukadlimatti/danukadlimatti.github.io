🛒 Walmart Confidence Interval and Central Limit Theorem (CLT) Analysis
📌 Project Overview
This project demonstrates the application of core statistical concepts—Confidence Intervals and the Central Limit Theorem (CLT)—using Walmart sales data. It is intended to showcase how statistical inference can help draw conclusions about a population from sample data and assist business decision-making under uncertainty.

🎯 Objectives
Apply the Central Limit Theorem to simulate sampling distributions.

Construct Confidence Intervals to estimate the population mean.

Perform visual analysis to demonstrate the stability of sample means.

Explain how statistical concepts translate to business insights.

📂 Dataset
The dataset used in this project contains daily/weekly sales data from different Walmart stores and departments. It includes:

Store ID

Department ID

Weekly Sales

Date

Holiday Flag (1 if holiday, 0 otherwise)

🧪 Key Concepts Implemented
Central Limit Theorem: Demonstrated how the sampling distribution of the sample mean becomes approximately normal as the sample size increases.

Confidence Intervals: Constructed 95% and 99% confidence intervals for the weekly sales mean using:

Known sample means and standard deviations

Standard error calculations

Sampling Techniques: Drew multiple random samples and analyzed their behavior.

Business Insights: Identified reliable average weekly sales metrics for making inventory or staffing decisions.

📊 Tools and Technologies
Python

pandas, numpy for data manipulation

matplotlib, seaborn for visualization

scipy.stats for statistical functions

📈 Visualizations
Distribution of weekly sales

Histograms of sample means with varying sample sizes

Confidence interval plots

🧠 Business Takeaway
Using statistical inference, Walmart can confidently estimate true average weekly sales and reduce risk in planning.

Larger sample sizes lead to more precise estimates, supporting decisions like store stocking and staff scheduling.
