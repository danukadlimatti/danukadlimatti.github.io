
📺 Netflix Data Exploration and Visualization
📌 Project Overview
This project dives into exploratory data analysis (EDA) of Netflix's content dataset. It aims to uncover trends in content types, release patterns, and geographic distribution, and provide actionable insights through data cleaning and visual storytelling.

🎯 Objectives
Perform data cleaning to handle null values and inconsistent formats.

Explore content types (TV Shows vs Movies), genre diversity, and release trends.

Analyze top contributing countries and most common directors and actors.

Visualize content growth and availability patterns over time.

📂 Dataset
The dataset was sourced from Netflix's public catalog data on Kaggle. It includes:

Title, Type (Movie/TV Show)

Director, Cast, Country

Date Added, Release Year

Rating, Duration

Genre (Listed in listed_in column)

Description

🧪 Key Analysis Performed
Null value treatment and removal of duplicates.

Year-wise content addition trends.

Top genres for movies and shows.

Country-wise distribution of content.

Most frequent directors and actors on the platform.

Comparison of TV Shows vs Movies in terms of volume and duration.

📊 Tools and Technologies
Python

pandas, numpy for data manipulation

matplotlib, seaborn for visualization

datetime, collections for processing date and list data

📈 Visualizations
Bar chart of top countries producing Netflix content

Line graph showing content addition over years

Heatmaps and word clouds for genre/actor insights

Pie charts for content type distribution

🧠 Insights
Netflix added the most content between 2017–2020.

Movies dominate over TV shows, but TV shows have grown rapidly post-2018.

The U.S. and India are top contributors of content.

Documentaries and Dramas are the most prevalent genres.
